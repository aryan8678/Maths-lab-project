# BMAT202P — Probability and Statistics Lab Project

**Title:** Statistical Analysis of Diabetes & Lifestyle Risk Factors (CDC BRFSS 2015), with a Classical Design-of-Experiments Supplement

Full plan: [`Maths_implementation.md`](Maths_implementation.md)

## Status

**Phase 1 (BRFSS-only labs) implemented: Lab 0 – Lab 11.**
Phase 2 (paired t-test on `MASS::anorexia`, RBD on `npk`, Latin Square on

## Structure

Each lab lives in its own directory so the labs can be assembled into the
final report independently:

```
data/                          shared datasets (raw + generated)
Lab00_Setup/                   package install, sampling, sanity checks
Lab01_Data_Types/               variable typing, cleaning, export
Lab02_Summary_Stats/            descriptive stats + 5 chart types
Lab03_Correlation_Regression/   correlation + simple linear regression
Lab04_Multiple_Regression/      multiple linear regression
Lab05_Binomial_Fitting/         Binomial distribution fit + chi-sq GOF
Lab06_Normal_Poisson_Fitting/   Normal (BMI) and Poisson (PhysHlth) fits
Lab07_OneSample_Tests/          one-sample t-test and proportion test
Lab08_TwoSample_Tests/          two-sample t-test and proportion test
Lab09_Paired_TTest/             independent-samples t-test (paired half is Phase 2)
Lab10_ChiSquare_Tests/          GOF + contingency chi-square tests
Lab11_ANOVA_CRD/                one-way ANOVA (CRD) + Tukey HSD
report/                        final report assembly (Phase 2+)
```

Each lab directory contains:
- one `.R` script, numbered to match the lab
- an `output/` folder with the script's text results (`.txt`) and chart PNGs

## Running

Open the project root in RStudio, then run each lab's script **in order**
with its own directory as the working directory (each script uses relative
paths like `../data/...` and `output/...`). In RStudio: open the `.R` file,
`Session > Set Working Directory > To Source File Location`, then run.

Lab 0 must run first — it installs packages and writes
`data/brfss_sample.csv`. Lab 1 must run before Labs 2–11 — it writes
`data/brfss_clean.csv`, which every later lab reads.

## Data

- `data/diabetes_012_health_indicators_BRFSS2015.csv` — full CDC BRFSS 2015
  dataset (253,680 rows), 3-class target `Diabetes_012`. Lab 0 derives the
  binary target `Diabetes_binary` from it (0 = No, 1 or 2 = Yes).
- `data/brfss_sample.csv` — reproducible n = 3000 working subsample
  (generated by Lab 0).
- `data/brfss_clean.csv` — typed/cleaned version of the sample (generated
  by Lab 1).
